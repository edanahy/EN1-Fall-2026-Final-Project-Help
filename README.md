# EN1 Fall 2026 — Final Project Help

Welcome! This repository holds **small example projects and starter code** to help you get unstuck on your EN1 final project.

## What to do

1. **Find the folder for your project** in the list above (in the file listing on GitHub). Your instructor will tell you which one is yours.
2. **Open that folder and read its `README.md`.** It explains what the example shows, what you need, and exactly how to run it.
3. **Download or copy the example** and get it running on your own computer.
4. **Make it your own.** These examples are intentionally simple. They show *how the pieces fit together*, and it's up to you to expand them, add features, improve the look, and turn them into your final project.

## How to get the files

- **Easiest:** click the green **Code** button → **Download ZIP**, then unzip and open your project's folder.
- **Or, with git:** `git clone <this repo's URL>`

You only need the one folder for your project. You can ignore the rest.

## Good to know

- **Many examples are a single `index.html`.** Download it and double-click to open it in your browser. No installation needed.
- **Some need a little more setup**, such as Python, a local web server, or a hub connection. Each project's README walks you through it step by step.
- **Some projects need a secret key** (for example, to use an AI service). Those READMEs will say so. **Contact your instructor** to get one. Never post keys publicly or commit them to GitHub.
- Stuck? Re-read the project README, then ask your instructor or a teammate.

Good luck, and have fun building!
