EN1 Final Project Help

Find your project below, then open its folder and read the README. These examples are starting points. Download the folder and make it your own!

Projects

  • fish-aquarium: webcam → AI cutout → swimming fish. Needs setup (Python server + optional OpenAI key), see README. Not a live demo.
  • claw-machine: webcam body pose → pretend claw-machine robot commands (browser only, needs internet + camera; nothing to install).
  • tabletop-arena: SPIKE Prime robot (2 motors + force sensor) over Bluetooth as a game controller, with a calibration screen. Browser only (Chrome/Edge); has a keyboard mode so it works without a hub.
  • wack-a-pirate: two SPIKE Prime hubs talking over Bluetooth (spikecomm). A whack-a-mole hub with popping color sensors broadcasts hits; a second hub drives a ship forward. Needs two hubs, see README. Not a live demo.
  • web-bt: reusable example + protocol notes for connecting any web page to a SPIKE Prime hub over Bluetooth (live print() output and sensor data). Start here for any SPIKE-to-web idea.

Tip: you can also download this whole repo from GitHub (Code → Download ZIP) and open any project's index.html directly in your browser.
